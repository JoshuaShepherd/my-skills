# The register watchlist

A watchlist, not a ban list. Run the costume test on each marker before cutting it.

> **Could you swap it for a plainer word with no loss of meaning?**
> Yes → it was costume. Cut it.
> No → it is a real term of art. Keep it.

Most of the time, in Movemental copy, these are costume.

| Marker | Usual plain meaning |
|---|---|
| substrate | basis, foundation, the thing underneath |
| scaffold / scaffolding | structure, support, starting point |
| surface (verb) | show, raise, bring up |
| artifact | thing, document, output, file |
| load-bearing | essential, the part everything rests on |
| leverage (verb) | use, build on |
| robust | strong, reliable, holds up |
| unlock | make possible, free up |
| operationalize | put to work, do |
| primitive (noun) | basic building block |
| ecosystem | the world around it |
| unpack | look at closely, explain |
| at scale | as it grows, widely |
| deeply / fundamentally | usually cut; let the claim stand |

The pattern: when the word names a real, specific thing in its home field, it stays. When it has wandered into abstract writing to sound rigorous, it goes. The packaged `plain-prose` skill carries the full domain-by-domain version of this list. This skill and that skill agree; use `plain-prose` when the task is specifically clarity and de-jargoning.
