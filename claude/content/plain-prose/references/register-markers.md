# Register markers — a watchlist by domain

This is a watchlist, not a banned list. Every word here can be the right word in its home field. Run the costume-or-term-of-art test before cutting: *could you swap it for a plainer word with no loss of meaning?* If yes, swap. If no, keep.

The words are grouped by the dialect they come from, because hearing the dialect is what lets you catch the next word that is not on the list.

## Systems / infrastructure / AI English

The accent of engineers, infra, and AI culture. Borrows from construction and machinery.

| Marker | Usual plain meaning |
|---|---|
| substrate | basis, foundation, the thing underneath |
| scaffold / scaffolding | structure, support, frame, starting point |
| primitive (as a noun) | basic building block, basic part |
| surface (as a verb) | show, raise, bring up, reveal |
| artifact | thing, document, output, file, result |
| load-bearing | essential, the part everything depends on |
| robust | strong, reliable, holds up |
| leverage (as a verb) | use, build on |
| orchestrate | coordinate, run, arrange |
| pipeline | process, sequence of steps |
| stack (as in "the X stack") | the set of tools, the layers |
| surface area | the parts exposed, what's at risk |
| composable | works in pieces that fit together |

## Consulting / business / strategy English

The accent of decks, strategy memos, and LinkedIn. Reaches for motion and machinery.

| Marker | Usual plain meaning |
|---|---|
| operationalize | put to work, make it run, do it |
| actionable | something you can act on, useful |
| optimize | improve, tune, make better |
| unlock (value, etc.) | make possible, free up, get to |
| double down | commit harder, do more of |
| north star | the goal, the thing we aim at |
| flywheel | the loop that builds on itself |
| lever (as in "the key lever") | the thing that moves it, what matters |
| bandwidth (for time) | time, capacity |
| at scale | as it grows, in large numbers |
| value-add | what it adds, why it helps |
| drive (alignment, etc.) | create, build, produce |
| ecosystem | the world around it, the set of related things |

## Academic / theory English

The accent of seminar rooms and journals. Reaches for abstraction to sound careful.

| Marker | Usual plain meaning |
|---|---|
| unpack | look at closely, break down, explain |
| interrogate (an idea) | question, examine, test |
| foreground / centre | emphasize, put first, focus on |
| problematize | complicate, question, show the trouble in |
| valence | charge, feeling, slant |
| lens (through the lens of) | way of seeing, from the angle of |
| modality | way, form, mode |
| instantiate | be an example of, show up as, make real |
| dialectic | back-and-forth, tension between two things |

## Vague intensifiers and hedges

Not metaphors, but the same instinct — reaching for weight without adding meaning. Usually just cut them.

| Marker | What to do |
|---|---|
| deeply, fundamentally, profoundly | usually cut; let the claim carry its own weight |
| at the end of the day | cut |
| in many ways | cut, or name the ways |
| it's worth noting that | cut; just note it |
| arguably | cut, or make the argument |
| a kind of / a sort of | cut, or commit to the real word |
| meaningfully, materially | cut, or say how much |

## Extended before / afters

**Systems English:**
- "We need to scaffold the onboarding flow before we surface it to users." → "We need to build the onboarding flow before we show it to users."
- "Authentication is a load-bearing primitive in the stack." → "Authentication is one of the basic parts everything depends on."
- "This artifact captures the team's decisions." → "This document captures the team's decisions."

**Consulting English:**
- "We'll operationalize the strategy to unlock value at scale." → "We'll put the strategy to work so it pays off as we grow."
- "Trust is the key lever, and the flywheel compounds from there." → "Trust is what moves everything, and it builds on itself from there."
- "Let's double down on the north star." → "Let's commit harder to the goal."

**Academic English:**
- "Let's unpack the dialectic and interrogate its valence." → "Let's look closely at the tension between the two ideas, and question which way it leans."
- "This instantiates the broader modality of formation." → "This is one example of how formation usually works."

## When to keep the word

Real terms of art, in their home field, stay:
- *substrate* — chemistry, biology
- *artifact* — software builds, archaeology, machine learning (a real, named output)
- *load-bearing* — actual architecture
- *primitive* — graphics or type theory (a genuine basic operation)
- *pipeline* — when describing a literal data pipeline to people who build them
- *dialectic* — when teaching philosophy and the word is the subject

The test never changes. If a plainer word would lose meaning, the word is doing real work. Keep it. If not, it was costume. Cut it.
